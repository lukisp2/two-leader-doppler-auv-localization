# Release status

Updated 2 November 2026.

## Available now

- Source code and per-run results are public in tag `v1.2.0`.
- The complete 100-run difficult-start dataset is attached to the
  [version 1.2.0 release](https://github.com/lukisp2/two-leader-doppler-auv-localization/releases/tag/v1.2.0).
- The original software and data remain available through the Zenodo links
  in the [README](README.md).

The new download was checked after publication. Its scientific results match
the locally evaluated experiment. The eight new tests passed, and recalculation
from all 100 saved trajectories reproduced the reported outcomes. The full
historical test suite was not rerun for version 1.2.0.

## Not included in the new download

The earlier 400-run controller comparison has public per-run results in this
repository, but its full trajectory archive is not part of the difficult-start
download or the original Zenodo records. Neither later experiment has a new DOI.

The source tag was created before the raw-data upload, so its original documents
say the upload was pending. Publication is now complete; the tag itself has not
been changed. The release page and this document give the current availability.

See [release notes](RELEASE_NOTES.md) for scientific changes and limitations,
and [reproduction instructions](docs/REPRODUCIBILITY.md) for technical details.
